# Terminal UTF-8 Locale Fix Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ensure every shell launched by Terminal App starts with a UTF-8 locale so Chinese filenames render correctly in `ls`.

**Architecture:** Keep the locale guarantee at the `ShellLauncher` → SwiftTerm PTY environment boundary. Make environment construction injectable and deterministic, then verify it with a focused standalone Swift assertion harness because this generated project currently has no test target or shared test scheme.

**Tech Stack:** Swift 5 / Foundation, standalone Swift assertion harness, Xcode project generated by `gen_xcodeproj.py`, SwiftTerm 1.x.

## Global Constraints

- Force `LANG`, `LC_ALL`, and `LC_CTYPE` to `zh_TW.UTF-8`.
- Preserve `TERM`, `TERM_PROGRAM`, `COLORTERM`, and Homebrew PATH setup.
- Do not modify `~/.zshrc`, global shell settings, filenames, or SwiftTerm rendering.
- New Swift files must be added to `gen_xcodeproj.py` before running `python3 gen_xcodeproj.py`.
- Use test-first red/green cycles before production changes.

```swift
func values(_ environment: [String]) -> [String: String] {
    Dictionary(uniqueKeysWithValues: environment.map {
        let parts = $0.split(separator: "=", maxSplits: 1).map(String.init)
        return (parts[0], parts.count == 2 ? parts[1] : "")
    })
}
```

```swift
static func buildEnvironment(
    base: [String: String] = ProcessInfo.processInfo.environment
) -> [String] {
    var env = base
    env["TERM"] = "xterm-256color"
    env["TERM_PROGRAM"] = "Apple_Terminal"
    env["COLORTERM"] = "truecolor"
    env["LANG"] = "zh_TW.UTF-8"
    env["LC_ALL"] = "zh_TW.UTF-8"
    env["LC_CTYPE"] = "zh_TW.UTF-8"
    let path = env["PATH"] ?? ""
    if !path.contains("/opt/homebrew/bin") {
        env["PATH"] = "/usr/local/bin:/opt/homebrew/bin:" + path
    }
    return env.map { "\($0.key)=\($0.value)" }
}
```
