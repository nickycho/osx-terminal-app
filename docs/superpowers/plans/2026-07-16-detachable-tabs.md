# Detachable Terminal Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Allow a tab to be dragged outside the main tab bar into an independent macOS window while preserving its existing PTY session, and terminate it when that window closes.

**Architecture:** Keep every `TerminalTab` and `TerminalViewModel` in `TabManager`, adding an `isDetached` flag so schedules and session references remain addressable. Use an AppKit `NSDraggingSource` handle to detect drag completion outside the main window, and a strongly-held `NSWindowController` to host the same terminal view model.

**Tech Stack:** SwiftUI, AppKit, SwiftTerm, Xcode project generated by `gen_xcodeproj.py`, standalone Swift behavior harness.

## Global Constraints

- Reuse the existing `TerminalViewModel` and `LocalProcessTerminalView`; never start a second shell for a detached tab.
- Closing a detached window must call `TabManager.closeTab(id:)` and terminate that tab's session.
- Main-window tab reordering must continue to work.
- Detached tabs remain in `TabManager.tabs` and `viewModels` for schedule/session lookup, but are filtered out of the main tab bar and terminal ZStack.
- Every new Swift file must be added to `gen_xcodeproj.py` `SOURCE_FILES` before regenerating the Xcode project.
- Run a failing behavior harness before production implementation, then run it again after each minimal implementation step.

### Task 3: Add the AppKit drag source

**Files:**
- Create: `TerminalApp/Views/TabDragSourceView.swift`

**Interfaces:**
- Produces `TabDragSourceView(tabID:onDragStarted:onDragEnded:onClick:onDetach:)` as an `NSViewRepresentable`.
- Calls `onDetach(tabID)` only when a drag ends with `.none` outside the source window frame.

- [x] **Step 1: Implement the drag-source bridge**

Implement the bridge around this concrete contract:

```swift
struct TabDragSourceView: NSViewRepresentable {
    let tabID: UUID
    let onDragStarted: () -> Void
    let onDragEnded: () -> Void
    let onClick: () -> Void
    let onDetach: (UUID) -> Void

    func makeNSView(context: Context) -> TabDragSourceNSView {
        let view = TabDragSourceNSView()
        view.tabID = tabID
        view.onDragStarted = onDragStarted
        view.onDragEnded = onDragEnded
        view.onClick = onClick
        view.onDetach = onDetach
        return view
    }

    func updateNSView(_ view: TabDragSourceNSView, context: Context) {
        view.tabID = tabID
        view.onDragStarted = onDragStarted
        view.onDragEnded = onDragEnded
        view.onClick = onClick
        view.onDetach = onDetach
    }
}

final class TabDragSourceNSView: NSView, NSDraggingSource {
    var tabID: UUID = UUID()
    var onDragStarted: (() -> Void)?
    var onDragEnded: (() -> Void)?
    var onClick: (() -> Void)?
    var onDetach: ((UUID) -> Void)?
    private var draggingSession: NSDraggingSession?

    override func mouseDragged(with event: NSEvent) {
        guard draggingSession == nil else { return }
        let item = NSPasteboardItem()
        item.setString(tabID.uuidString, forType: .string)
        let dragItem = NSDraggingItem(pasteboardWriter: item)
        dragItem.setDraggingFrame(bounds, contents: nil)
        draggingSession = beginDraggingSession(with: [dragItem], event: event, source: self)
        onDragStarted?()
    }

    func draggingSession(_ session: NSDraggingSession,
                         endedAt screenPoint: NSPoint,
                         operation: NSDragOperation) {
        if operation == [] && !(window?.frame.contains(screenPoint) ?? true) {
            onDetach?(tabID)
        }
        draggingSession = nil
        onDragEnded?()
    }
}
```

`mouseDown`/`mouseUp` must call `onClick` only when no drag session started. `updateNSView` must refresh closures and the UUID without replacing the view.

- [x] **Step 2: Keep drag state cleanup deterministic**

Call `onDragEnded` from both the drag-session completion path and a non-drag mouse-up path. Ensure a second `mouseDragged` cannot start another session while one is active.

### Task 4: Add detached window ownership

**Files:**
- Create: `TerminalApp/App/TerminalWindowManager.swift`

**Interfaces:**
- Produces `TerminalWindowManager.attach(tabManager:)`, `detach(tabID:)`, and `closeDetached(tabID:)`.
- Produces `DetachedTerminalWindowController` with `NSWindowDelegate.windowWillClose`.

- [x] **Step 1: Implement manager and controller**

Keep `[UUID: DetachedTerminalWindowController]` strongly in the manager. The public operations must follow this shape:

```swift
final class TerminalWindowManager: NSObject, ObservableObject {
    private(set) weak var tabManager: TabManager?
    private var controllers: [UUID: DetachedTerminalWindowController] = [:]

    func attach(tabManager: TabManager) { self.tabManager = tabManager }
    func detach(tabID: UUID) {
        guard let tabManager,
              let tab = tabManager.tabs.first(where: { $0.id == tabID }),
              !tab.isDetached,
              controllers[tabID] == nil else { return }
        let viewModel = tabManager.viewModel(for: tab)
        tabManager.detachTab(id: tabID)
        let view = DetachedTerminalWindowView(viewModel: viewModel)
        let window = NSWindow(contentViewController: NSHostingController(rootView: view))
        let controller = DetachedTerminalWindowController(window: window, tabID: tabID)
        controller.windowManager = self
        controllers[tabID] = controller
        window.title = tab.displayTitle
        window.delegate = controller
        window.setContentSize(NSSize(width: 800, height: 600))
        window.center()
        window.makeKeyAndOrderFront(nil)
    }

    func closeDetached(tabID: UUID) {
        guard controllers.removeValue(forKey: tabID) != nil else { return }
        tabManager?.closeTab(id: tabID)
    }
}

final class DetachedTerminalWindowController: NSWindowController, NSWindowDelegate {
    let tabID: UUID
    weak var windowManager: TerminalWindowManager?

    func windowWillClose(_ notification: Notification) {
        windowManager?.closeDetached(tabID: tabID)
    }
}
```

`detach(tabID:)` must get the existing tab and `tabManager.viewModel(for:)`, call `tabManager.detachTab(id:)`, create an `NSWindow` hosting `DetachedTerminalWindowView`, set the title from `tab.displayTitle`, set `window.delegate`, center/show it, and revert `isDetached` if window creation fails. `closeDetached(tabID:)` must be idempotent: remove the controller and call `tabManager.closeTab(id:)` exactly once.
